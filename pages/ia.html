Aprenda a Usar IA com Eficiência: Menos Custo, Mais Velocidade

Utilizar IA no desenvolvimento de software não é apenas "conversar com o chat". Trata-se de saber qual modo escolher (Agent, Ask ou Plan), dominar o uso de Skills e Ferramentas, economizar tokens e construir prompts cirúrgicos que resolvem o problema de primeira sem alucinações.

🧠

1. O que são Tokens?

Tokens são fragmentos de palavras e caracteres que a IA processa. Cada arquivo ou histórico acumulado consome sua janela de contexto e eleva o custo/tempo de resposta.

Regra: Contexto Limpo
🤖

2. Agentes vs Chat

Chat apenas responde texto estático. Agentes de IA possuem ferramentas (Tool Calling): leem arquivos, rodam testes no terminal, inspecionam o projeto e corrigem erros de forma autônoma.

Autonomia & ReAct
🎯

3. Skills & MCP

Skills são pacotes modulares de regras e conhecimento carregados apenas sob demanda. O MCP conecta a IA a bancos, repositórios e serviços externos sem inflar o prompt.

Contexto Modular
⚡

4. Prompt Cirúrgico

Prompts vagos geram código quebrado e retrabalho. O padrão de ouro é: [Papel] + [Código/Arquivo exato] + [Objetivo] + [Restrições] + [Formato de saída].

🧪 Laboratório de Engenharia de Prompt: Veja a Diferença

Economize tempo e tokens

Clique nos cenários abaixo para comparar um prompt amador (que gasta tokens e gera alucinações) com um prompt direto e profissional:

❌ Prompt Ruim (Gasta Tokens & Vago)
"Oi copilot, tudo bem? Meu código Java tá dando erro no backend, você pode me ajudar a consertar? É sobre usuário."
  • Sem contexto de arquivo ou stack trace.
  • Faz a IA adivinhar o problema e gastar centenas de tokens perguntando.
  • Gera respostas genéricas e código que não compila no seu projeto.
✅ Prompt de Elite (Cirúrgico & Econômico)
"No arquivo #UsuarioService.java, corrija o método buscarPorEmail() que lança NullPointerException ao passar email inexistente. Retorne Optional<UsuarioResponseDTO>. Não altere a assinatura dos outros métodos."
  • Arquivo e método exatos referenciados (#file).
  • Problema específico e comportamento esperado descritos.
  • Restrições claras para evitar alterações desnecessárias.
🧩 Skills, MCP & Arquitetura de Agentes Fundamentos Avançados ▶
O que é uma Skill: Pacote modular de instruções e regras carregado sob demanda Em vez de colocar 5.000 linhas de regras no prompt principal, criam-se Skills especializadas. A IA só lê a Skill quando a tarefa específica (ex: migração de banco, Docker, testes) é solicitada, economizando até 90% de tokens.
O que é MCP (Model Context Protocol): Protocolo universal para conectar a IA a dados externos Criado pela Anthropic e adotado pela indústria, o MCP permite que a IA acerte consultas a bancos SQL, GitHub, Jira e APIs locais via servidores padronizados com controle de permissão e segurança.
Ciclo ReAct (Reason + Act): O cérebro do Agente Autônomo O agente não responde de imediato: ele 1) Pensa (Raciocina), 2) Escolhe uma ferramenta (ler arquivo/rodar comando), 3) Observa o resultado real e 4) Repete o ciclo até a solução estar 100% verificada.
Subagentes Especializados: Dividir para conquistar tarefas grandes Um agente orquestrador pode invocar subagentes dedicados (ex: Subagente de Pesquisa de Código, Subagente de Testes, Subagente de Revisão de Segurança), mantendo a janela de contexto de cada um enxuta e focada.
💰 Economia Extrema de Tokens & Janela de Contexto Performance & Custo ▶
Regra #1: Use referências pontuais (#file, #selection) em vez de colar o arquivo todo Quando você seleciona 10 linhas e usa #selection, a IA consome apenas 50 tokens. Se colar um arquivo de 1.000 linhas, consumirá 4.000 tokens e terá mais chance de alucinar ou esquecer detalhes.
Regra #2: Abra uma nova sessão (New Chat / /clear) ao mudar de assunto Histórico longo de chat envia todas as mensagens anteriores em cada nova requisição. Se a conversa já tem 20 mensagens, cada simples "ok" custará milhares de tokens repetidos. Reinicie o chat para novas tarefas.
Regra #3: Nunca cole logs inteiros de 10.000 linhas no chat Recorte apenas as 5 linhas do topo do Stack Trace onde aparece a exceção e a linha da sua classe. O resto do log de frameworks é ruído que consome contexto à toa.
Regra #4: Escolha o modelo certo (Flash / Mini para tarefas simples, Pro / Thinking para arquitetura) Modelos rápidos como Gemini 3.7 Flash ou Claude Haiku respondem em milissegundos com baixo custo. Use modelos mais pesados (Claude Opus, GPT-4o, o3-mini) apenas para refatorações profundas ou lógica complexa.
🎯 Fórmula do Prompt Perfeito & Hacks de Produtividade Prática Diária ▶
A Fórmula dos 5 Elementos: [Papel] + [Contexto/Arquivo] + [Ação] + [Restrições] + [Saída] Exemplo: "Como especialista em Spring Boot [Papel], altere a classe #UsuarioController.java [Contexto] para adicionar paginação no endpoint GET /usuarios [Ação]. Use Pageable e retorne Page<UsuarioDTO> [Restrições]. Mostre apenas o método alterado [Saída]."
Técnica 'Negative Constraints': Diga explicitamente o que NÃO fazer Para evitar que a IA delete comentários, renomeie métodos existentes ou invente dependências que você não usa, adicione sempre: "Não altere a assinatura existente" e "Não adicione novas dependências ao pom.xml".
Técnica 'Few-Shot': Dê 1 exemplo do formato que você quer Ao pedir DTOs, mappers ou testes, mostre um teste já existente no projeto como referência de estilo: "Siga o mesmo padrão de nomenclatura e asserções do arquivo #UsuarioServiceTest.java".
Instruções Customizadas: Crie o arquivo .github/copilot-instructions.md Defina regras globais do seu projeto (ex: "Use Java 21, Spring Boot 3, records para DTOs, JUnit 5 e nunca use System.out.println"). O Copilot lerá isso automaticamente em todas as conversas sem você precisar repetir.
📋 Templates Prontos de Alta Performance (Copie e Cole) Pronto para Uso ▶
Template: Debugging & Correção Rápida de Erro "Estou recebendo o erro [COLE_O_ERRO_AQUI] na linha [NUMERO] do arquivo #nome-do-arquivo.java. Analise a causa raiz, corrija o trecho preservando a lógica existente e explique em uma frase o que causou a falha."
Template: Criação de Testes Unitários com Mocks "Crie a classe de testes unitários para o arquivo #MeuService.java usando JUnit 5 e Mockito. Cubra o cenário de sucesso (caminho feliz) e os principais cenários de erro e exceções. Isole as dependências com @Mock e @InjectMocks."
Template: Refatoração Limpa (Clean Code & SOLID) "Refatore o método selecionado em #nome-do-arquivo.java para reduzir a complexidade ciclomática. Extraia métodos privados auxiliares com nomes expressivos e elimine código duplicado, sem alterar o comportamento externo."
Template: Revisão de Segurança & Performance "Faça um Code Review de segurança no arquivo selecionado. Verifique possíveis vulnerabilidades (SQL Injection, vazamento de memória, concorrência indevida ou validação de entrada ausente). Liste os pontos críticos em tópicos objetivos."
Template: Criação de CRUD / Endpoint com Validação "Crie o endpoint [GET/POST/PUT] no arquivo #Controller.java para a entidade [Nome]. Inclua DTO de request com validações (@NotBlank, @Positive), Service com a regra de negócio e tratamento para retorno HTTP adequado."
⌨️ Comandos de Barra (Slash Commands) & Contextos do Copilot Atalhos VS Code ▶
/fix : Corrige erros de compilação ou bugs no código selecionado Selecione o trecho com linha vermelha e digite /fix. O Copilot analisa os erros do Problems panel e propõe a correção exata.
/tests : Gera testes unitários imediatos para a classe ou método aberto Gera esqueleto completo com importações corretas de JUnit/Mockito respeitando a estrutura do seu projeto.
/explain : Explica o fluxo de execução e a lógica do trecho Excelente para ler código legado ou expressões regulares complexas antes de fazer qualquer alteração.
#terminalLastCommand & #terminalSelection : Contexto instantâneo do terminal Envie o último comando ou a saída do terminal direto para a IA sem precisar copiar e colar texto manualmente.
