💡 O que é o Front-End?
Front-End é a parte visual e interativa de uma aplicação. HTML estrutura o conteúdo, CSS estiliza e JavaScript dá vida à página. O navegador interpreta esses três pilares e transforma código em experiência.
🎯 Regra de ouro do Front-End

Construa primeiro uma estrutura semântica, depois estilize com CSS e só então adicione comportamento com JavaScript. Uma interface boa continua entendível sem depender de efeitos.

ROTEIRO DE ESTUDO

Como pensar antes de codar

Use este ciclo para transformar uma tela bonita em uma interface sólida.

01Estrutura

HTML semântico, formulários, hierarquia e acessibilidade.

main > section > article
02Estilo

CSS responsivo, layout, estados, contraste e manutenção.

grid + flex + variables
03Comportamento

Eventos, DOM, estado, validação e comunicação com APIs.

event -> state -> render
04Qualidade

Teste teclado, mobile, console, performance e estados de erro.

DevTools + Lighthouse
📄 HTML Estrutura ▶
<!DOCTYPE html><html lang="pt"><head><meta charset="UTF-8"><title>Título</title></head><body>Conteúdo</body></html> Estrutura básica de um documento HTML
<header><nav><main><section><article><aside><footer> Tags semânticas para estruturação do conteúdo
<h1>Título Principal</h1><h2>Subtítulo</h2><h3>Seção</h3> Hierarquia de títulos (h1 a h6)
<p>Parágrafo de texto</p> Parágrafo de texto
<a href="https://exemplo.com" target="_blank">Link</a> Link para outra página (abre em nova aba)
<img src="imagem.jpg" alt="Descrição" width="300" height="200"> Tag de imagem com atributos essenciais
<ul><li>Item 1</li><li>Item 2</li></ul> Lista não ordenada (UL) e ordenada (OL)
<table><thead><tr><th>Nome</th></tr></thead><tbody><tr><td>Valor</td></tr></tbody></table> Estrutura de tabela (thead, tbody, tr, th, td)
<form action="/submit" method="POST"><input type="text" name="nome" placeholder="Digite seu nome"><button type="submit">Enviar</button></form> Formulário com input e botão de submit
<div class="container"><span class="destaque">Texto</span></div> Div (bloco) e Span (inline) com classes
🎨 CSS Estilização ▶
.classe { propriedade: valor; } Seletor de classe - reutilizável
#id { propriedade: valor; } Seletor de ID - único na página
elemento { propriedade: valor; } Seletor de elemento (tag)
.container { display: flex; justify-content: center; align-items: center; gap: 10px; } Flexbox - alinhamento e distribuição
.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } Grid - layout em colunas
.card:hover { transform: translateY(-5px); box-shadow: 0 8px 30px rgba(0,0,0,0.2); } Hover - efeito ao passar mouse
@keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.1); } 100% { transform: scale(1); } } .animado { animation: pulse 2s infinite; } Keyframes - animação personalizada
:root { --cor-principal: #ff2800; --cor-fundo: #1a1a2e; } .card { background: var(--cor-fundo); color: var(--cor-principal); } Variáveis CSS - fácil manutenção
@media (max-width: 768px) { .container { flex-direction: column; } } Media Query - responsividade para mobile
.card { background: rgba(255,255,255,0.05); backdrop-filter: blur(10px); border: 1px solid rgba(255,255,255,0.1); } Glassmorphism - efeito de vidro
⚡ JavaScript - DOM Manipulação ▶
document.getElementById('id') Seleciona elemento por ID
document.querySelector('.classe') Seleciona o primeiro elemento com seletor CSS
document.querySelectorAll('.classe') Seleciona todos os elementos com seletor CSS
element.textContent = 'Novo texto' Altera o texto do elemento
element.innerHTML = '<strong>HTML</strong>' Altera o HTML interno do elemento
element.classList.add('ativo') Adiciona classe CSS
element.classList.remove('ativo') Remove classe CSS
element.classList.toggle('ativo') Alterna classe CSS (add/remove)
element.style.backgroundColor = '#ff2800' Altera estilo inline
document.createElement('div') Cria um novo elemento
parent.appendChild(child) Adiciona elemento filho
element.remove() Remove o elemento
🖱️ JavaScript - Eventos Interatividade ▶
element.addEventListener('click', () => { alert('Clicou!'); }); Evento de clique
element.addEventListener('mouseenter', () => { element.style.background = '#ff2800'; }); Evento ao passar mouse (entrar)
element.addEventListener('mouseleave', () => { element.style.background = 'transparent'; }); Evento ao sair do mouse
input.addEventListener('input', (e) => { console.log(e.target.value); }); Evento ao digitar em input
form.addEventListener('submit', (e) => { e.preventDefault(); console.log('Enviado!'); }); Evento de submit (previne recarregar página)
document.addEventListener('DOMContentLoaded', () => { console.log('Página carregada!'); }); Executa quando o DOM estiver pronto
window.addEventListener('scroll', () => { console.log('Scroll'); }); Evento ao rolar a página
element.addEventListener('keydown', (e) => { if (e.key === 'Enter') { console.log('Enter pressionado'); } }); Evento de tecla pressionada
🔄 JavaScript - Async / Await Assíncrono ▶
async function buscarDados() { const response = await fetch('https://api.exemplo.com/dados'); const data = await response.json(); console.log(data); } Função assíncrona com fetch
try { const data = await fetch('/api'); } catch (error) { console.error('Erro:', error); } Try/Catch para tratamento de erros
fetch('/api/usuarios').then(response => response.json()).then(data => console.log(data)).catch(error => console.error(error)); Promise com then/catch
const [response1, response2] = await Promise.all([fetch('/api/1'), fetch('/api/2')]); Promise.all - executa múltiplas requisições em paralelo
setTimeout(() => { console.log('Executou após 1s'); }, 1000); setTimeout - executa após X milissegundos
setInterval(() => { console.log('Executa a cada 2s'); }, 2000); setInterval - executa a cada X milissegundos
📊 JavaScript - Arrays Manipulação ▶
const numeros = [1, 2, 3, 4, 5]; Criação de array
numeros.map(num => num * 2) Map - transforma cada elemento
numeros.filter(num => num > 2) Filter - filtra elementos
numeros.reduce((acc, num) => acc + num, 0) Reduce - reduz array a um único valor (soma)
numeros.find(num => num > 3) Find - encontra primeiro elemento que atende condição
numeros.includes(3) Includes - verifica se elemento existe
numeros.forEach(num => console.log(num)) forEach - itera sobre os elementos
♿ HTML e acessibilidade Inclusão ▶
<button type="button" aria-label="Abrir menu">☰</button>Use button para ações e um nome acessível para leitores de tela.
<label for="email">E-mail</label><input id="email" type="email" required>Associe o label ao campo e use o tipo correto de input.
<img src="foto.jpg" alt="Descrição objetiva da imagem">Fornece texto alternativo para conteúdo não textual.
:focus-visible { outline: 3px solid #00ff88; }Deixa o foco do teclado visível sem poluir todo clique do mouse.
<main aria-labelledby="titulo">Dá uma região principal identificável à página.
🧩 CSS moderno Layout e manutenção ▶
:root { --space: 1rem; --surface: #1e1e1e; }Centraliza tokens para manter consistência visual.
.layout { display: grid; grid-template-columns: minmax(0, 1fr) 18rem; }Cria uma estrutura responsiva com colunas estáveis.
.cards { container-type: inline-size; }Prepara um componente para responder ao tamanho do próprio container.
@media (prefers-reduced-motion: reduce) { * { animation: none; transition: none; } }Respeita a preferência de usuários que reduzem movimento.
.texto { overflow-wrap: anywhere; }Evita que URLs e palavras longas estourem o layout.
🧠 JavaScript - estado e APIs Aplicações reais ▶
const state = { loading: false, data: [], error: null };Modele estados explícitos para evitar interfaces confusas.
button.addEventListener('click', () => state.open = !state.open);Atualiza estado a partir de uma interação do usuário.
const response = await fetch('/api/usuarios'); if (!response.ok) throw new Error('Falha na API');Trate status HTTP antes de tentar ler a resposta.
localStorage.setItem('tema', 'dark');Persiste uma preferência simples no navegador.
form.addEventListener('submit', event => { event.preventDefault(); });Controla o envio do formulário sem recarregar a página.
