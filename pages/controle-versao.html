💡 O que é Git?
Git é um sistema de controle de versão distribuído. Permite rastrear alterações no código, trabalhar em equipe, criar branches, fazer merges e muito mais. Domine os comandos commit, merge, rebase, stash e cherry-pick.
🚀 Inicialização e Configuração Setup ▶
git init Inicializa um repositório Git no diretório atual
git clone https://github.com/usuario/repo.git Clona um repositório remoto
git config --global user.name "Seu Nome" Configura nome de usuário global
git config --global user.email "seu@email.com" Configura email global
git config --list Lista todas as configurações do Git
git remote add origin https://github.com/usuario/repo.git Adiciona um repositório remoto
git remote -v Lista repositórios remotos configurados
📝 Commit e Stage Salvar ▶
git status Mostra o estado atual do repositório
git add arquivo.txt Adiciona um arquivo ao stage
git add . Adiciona todos os arquivos modificados ao stage
git add -A Adiciona TODOS os arquivos (incluindo removidos)
git add -p Adiciona partes específicas de um arquivo (interativo)
git commit -m "Mensagem do commit" Cria um commit com mensagem
git commit -am "Mensagem" Adiciona e commita em um só comando
git commit --amend -m "Nova mensagem" Altera a mensagem do último commit
git commit --amend --no-edit Adiciona alterações ao último commit sem mudar mensagem
git reset HEAD arquivo.txt Remove arquivo do stage (volta para working directory)
🌿 Branch e Merge Ramificação ▶
git branch Lista todas as branches
git branch -a Lista todas as branches (incluindo remotas)
git branch nova-branch Cria uma nova branch
git checkout nova-branch Muda para a branch especificada
git checkout -b nova-branch Cria e muda para a nova branch
git switch nova-branch Muda para a branch (alternativa moderna ao checkout)
git merge feature-branch Mescla a branch feature na branch atual
git merge --no-ff feature-branch Mescla criando um commit de merge (sem fast-forward)
git merge --abort Cancela o merge em andamento (resolve conflitos)
git branch -d branch Deleta uma branch (seguro)
git branch -D branch Força a deleção de uma branch
📜 Log e Histórico Histórico ▶
git log Mostra o histórico de commits
git log --oneline Histórico resumido (um commit por linha)
git log --graph --oneline --decorate Visualiza a árvore de commits com gráfico
git log -p Mostra as diferenças de cada commit
git log --author="nome" Filtra commits por autor
git log --since="2024-01-01" Commits desde uma data
git log -S "palavra" Busca commits que alteraram a "palavra"
git show commit-id Mostra detalhes de um commit específico
git diff Mostra alterações não commitadas
git diff --staged Mostra alterações no stage
🔄 Rebase e Cherry-Pick Histórico ▶
git rebase main Aplica commits da branch atual sobre a main
git rebase -i HEAD~3 Rebase interativo - reorganiza os últimos 3 commits
git rebase --continue Continua o rebase após resolver conflitos
git rebase --abort Cancela o rebase em andamento
git cherry-pick commit-id Aplica um commit específico na branch atual
git cherry-pick commit1..commit5 Aplica um intervalo de commits
git cherry-pick --continue Continua o cherry-pick após resolver conflitos
git cherry-pick --abort Cancela o cherry-pick em andamento
📦 Stash e Limpeza Temporário ▶
git stash Guarda alterações não commitadas temporariamente
git stash list Lista todos os stashes
git stash pop Recupera o último stash e o remove da lista
git stash apply Recupera o último stash sem remover
git stash drop stash@{0} Remove um stash específico
git stash clear Remove todos os stashes
git clean -fd Remove arquivos não rastreados
⏪ Reset e Revert Desfazer ▶
git reset --soft HEAD~1 Remove commit mas mantém alterações no stage
git reset --mixed HEAD~1 Remove commit e mantém alterações no working directory
git reset --hard HEAD~1 Remove commit e descarta alterações (PERIGOSO!)
git revert commit-id Cria um novo commit que desfaz um commit anterior
git revert --no-commit HEAD~1 Reverte sem criar commit automático
🌍 Remoto e Push/Pull Compartilhar ▶
git push origin main Envia commits para o repositório remoto
git push -u origin main Envia e configura a branch upstream
git push --force origin main Força o envio (sobrescreve histórico - CUIDADO!)
git push origin --delete branch Deleta uma branch remota
git pull origin main Puxa alterações do repositório remoto
git pull --rebase origin main Puxa e aplica rebase ao invés de merge
git fetch origin Baixa alterações sem mesclar
git remote show origin Mostra informações do repositório remoto
⚔️ Conflitos e Resolução Merge ▶
git status Identifica arquivos com conflito
git diff Mostra os conflitos linha a linha
git merge --abort Cancela o merge e volta ao estado anterior
git rebase --abort Cancela o rebase e volta ao estado anterior
git add . Marca arquivos como resolvidos
git commit Finaliza o merge ou rebase após resolver conflitos
🏷️ Tag e Release Versões ▶
git tag Lista todas as tags
git tag v1.0.0 Cria uma tag leve
git tag -a v1.0.0 -m "Versão 1.0.0" Cria uma tag anotada com mensagem
git push origin v1.0.0 Envia uma tag específica
git push origin --tags Envia todas as tags
git tag -d v1.0.0 Remove uma tag local
git push origin --delete v1.0.0 Remove uma tag remota
