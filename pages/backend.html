💡 O que é o Ecossistema Java?
O ecossistema Java é composto por Java (linguagem e JVM), Maven (gerenciador de dependências) e Spring Boot (framework para aplicações empresariais). Domine esses três pilares para se tornar um especialista back-end.
☕ Java - Fundamentos Linguagem ▶
public class Main { public static void main(String[] args) { ... } } Estrutura básica de uma classe Java com método main
List nomes = new ArrayList<>(); ArrayList - estrutura de dados dinâmica
Map mapa = new HashMap<>(); HashMap - chave/valor para buscas rápidas
Optional nome = Optional.ofNullable(valor); Optional - evita NullPointerException
list.stream().filter(s -> s.startsWith("A")).collect(Collectors.toList()); Streams - filtra elementos que começam com "A"
list.stream().map(String::toUpperCase).collect(Collectors.toList()); Streams - transforma todos para maiúsculo
list.stream().sorted(Comparator.reverseOrder()).collect(Collectors.toList()); Streams - ordenação reversa
record Pessoa(String nome, int idade) {} Record - classe imutável (Java 17+)
sealed class Animal permits Cachorro, Gato {} Sealed Class - controla herança (Java 17+)
String texto = """ Linha 1 Linha 2 """; Text Blocks - strings multilinha (Java 15+)
🗄️ Java - JDBC Banco de Dados ▶
Class.forName("com.mysql.cj.jdbc.Driver"); Carrega o driver JDBC (MySQL)
Connection conn = DriverManager.getConnection(url, user, pass); Estabelece conexão com o banco
Statement stmt = conn.createStatement(); Cria Statement para executar queries
ResultSet rs = stmt.executeQuery("SELECT * FROM usuarios"); Executa SELECT e retorna ResultSet
while(rs.next()) { String nome = rs.getString("nome"); } Itera sobre os resultados da consulta
PreparedStatement ps = conn.prepareStatement("INSERT INTO usuarios VALUES (?)"); PreparedStatement - previne SQL Injection
ps.setString(1, "João"); ps.executeUpdate(); Define parâmetro e executa INSERT/UPDATE/DELETE
conn.setAutoCommit(false); conn.commit(); Controle de transação (commit/rollback)
🏗️ Java - Hibernate / JPA ORM ▶
@Entity public class Usuario { @Id private Long id; } Define uma entidade JPA com chave primária
@OneToMany(mappedBy = "usuario", cascade = CascadeType.ALL) Relacionamento OneToMany com cascade
@ManyToOne @JoinColumn(name = "usuario_id") Relacionamento ManyToOne com chave estrangeira
@Query("SELECT u FROM Usuario u WHERE u.nome LIKE %:nome%") JPQL Query com parâmetro nomeado
@Query(value = "SELECT * FROM usuarios", nativeQuery = true) Native Query (SQL puro)
session.createQuery("FROM Usuario").list(); Hibernate Session - busca todos os usuários
@Cacheable @Cache(usage = CacheConcurrencyStrategy.READ_WRITE) Cache de segundo nível (Hibernate)
@EntityGraph(attributePaths = {"enderecos"}) EntityGraph - evita N+1 queries
🧪 Java - Testes Qualidade ▶
@Test void deveCalcularSoma() { assertEquals(5, calculadora.somar(2, 3)); } JUnit 5 - teste simples com assert
@BeforeEach void setup() { ... } Executa antes de cada teste
@Mock private UsuarioService service; @InjectMocks private UsuarioController controller; Mockito - cria mocks e injeta no controller
when(service.buscar(1L)).thenReturn(usuario); Mockito - define comportamento do mock
verify(service, times(1)).buscar(1L); Mockito - verifica se método foi chamado
@Testcontainers @Container static PostgreSQLContainer postgres = new PostgreSQLContainer<>("postgres:15"); Testcontainers - banco de dados real para testes
assertThat(usuario.getNome()).isEqualTo("João"); AssertJ - asserts fluentes
⚡ Java - Threads & Concorrência Performance ▶
new Thread(() -> System.out.println("Olá")).start(); Cria e inicia uma thread com lambda
ExecutorService executor = Executors.newFixedThreadPool(10); Pool de threads com 10 threads
executor.submit(() -> System.out.println("Task")); Submete task para execução no pool
CompletableFuture.supplyAsync(() -> "Resultado").thenAccept(System.out::println); CompletableFuture - programação assíncrona
CompletableFuture.allOf(f1, f2).join(); Aguarda múltiplos futures completarem
synchronized void metodo() { ... } Synchronized - exclusão mútua
ReentrantLock lock = new ReentrantLock(); lock.lock(); try { ... } finally { lock.unlock(); } Lock - controle mais fino que synchronized
📐 Java - Design Patterns Arquitetura ▶
public class Singleton { private static final Singleton INSTANCE = new Singleton(); } Singleton - garante única instância
public class UsuarioBuilder { private String nome; public UsuarioBuilder nome(String nome) { this.nome = nome; return this; } } Builder - constrói objetos complexos
public class UsuarioFactory { public static Usuario criarAdmin() { ... } } Factory - cria objetos com lógica
public class Observable { private List observers = new ArrayList<>(); } Observer - notifica mudanças
public interface Strategy { int executar(int a, int b); } Strategy - algoritmos intercambiáveis
📦 Maven Build ▶
mvn clean Limpa o diretório target (remove classes compiladas)
mvn compile Compila o código fonte
mvn test Executa os testes unitários
mvn package Gera o JAR/WAR da aplicação
mvn install Instala o artefato no repositório local
mvn clean install Limpa, compila, testa e instala
mvn spring-boot:run Roda aplicação Spring Boot
mvn dependency:tree Mostra árvore de dependências
mvn clean package -DskipTests Pula os testes durante o build
mvn versions:display-dependency-updates Verifica atualizações de dependências
<dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-web</artifactId></dependency> Spring Boot Starter Web - dependência
<dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-data-jpa</artifactId></dependency> Spring Boot JPA - dependência
<dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-security</artifactId></dependency> Spring Boot Security - dependência
mvn clean compile assembly:single Gera JAR com todas as dependências (fat jar)
🍃 Spring Boot - Core Essencial ▶
@SpringBootApplication Anotação principal - combina @Configuration, @EnableAutoConfiguration, @ComponentScan
@RestController @RequestMapping("/api/usuarios") Controller REST com endpoint /api/usuarios
@GetMapping @PostMapping @PutMapping @DeleteMapping Mapeamento de métodos HTTP
@PathVariable Long id Captura variável da URL (ex: /api/usuarios/1)
@RequestBody Usuario usuario Converte JSON do body para objeto
@Autowired private UsuarioService service; Injeção de dependência
@Component @Service @Repository Anotações para Spring Beans
@Value("${app.name}") private String appName; Injeta valor do application.properties
@ConfigurationProperties(prefix = "app") Mapeia configurações em um POJO
@Profile("dev") Ativa bean apenas no profile "dev"
📊 Spring Boot - JPA / Data Banco ▶
public interface UsuarioRepository extends JpaRepository<Usuario, Long> Repository - CRUD básico automático
List findByNomeContaining(String nome); Query Method - busca por parte do nome
Page findAll(Pageable pageable); Paginação com Pageable
@Query("SELECT u FROM Usuario u WHERE u.idade > :idade") JPQL Query personalizada
@Modifying @Query("UPDATE Usuario u SET u.ativo = false WHERE u.id = :id") Update/Delete com JPQL
@EntityListeners(AuditingEntityListener.class) Auditoria automática (criado em, atualizado em)
@Transactional Gerencia transações automaticamente
spring.jpa.show-sql=true Mostra SQL gerado no console
spring.jpa.hibernate.ddl-auto=update Atualiza schema automaticamente
🔒 Spring Boot - Security Segurança ▶
@EnableWebSecurity Habilita segurança Web
SecurityFilterChain filterChain(HttpSecurity http) throws Exception { http.authorizeHttpRequests(auth -> auth.anyRequest().authenticated()).formLogin(); } Configuração básica de segurança
@PreAuthorize("hasRole('ADMIN')") Restringe acesso a ADMIN
public class UserDetailsService { ... } Carrega usuário para autenticação
BCryptPasswordEncoder encoder = new BCryptPasswordEncoder(); Encripta senhas com BCrypt
JwtTokenProvider tokenProvider = new JwtTokenProvider(); Geração e validação de JWT
@WithMockUser(username = "admin", roles = "ADMIN") Mock usuário em testes
📈 Spring Boot - Actuator Monitoramento ▶
spring-boot-starter-actuator Dependência para Actuator
management.endpoints.web.exposure.include=* Expõe todos os endpoints
/actuator/health Endpoint de saúde da aplicação
/actuator/metrics Métricas da aplicação (CPU, memória, etc)
/actuator/info Informações customizadas da aplicação
@ReadOperation @WriteOperation Cria endpoints customizados
☁️ Spring Boot - Cloud Microservices ▶
@EnableDiscoveryClient Registra serviço no Service Discovery (Eureka)
@EnableFeignClients Habilita Feign Client para chamadas HTTP
@FeignClient(name = "servico-usuario") Cliente Feign para chamar outro serviço
@EnableCircuitBreaker Habilita Circuit Breaker (Resilience4j)
@RefreshScope Atualiza configurações sem reiniciar
@EnableConfigServer Servidor de configuração centralizada
@EnableZuulProxy / @EnableGateway API Gateway para roteamento
