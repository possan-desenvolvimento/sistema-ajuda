💡 O que é o Terminal Linux?
O terminal é a interface de linha de comando do Linux. Com ele você pode executar programas, gerenciar arquivos, monitorar processos e controlar todo o sistema de forma eficiente. Domine os comandos básicos ls, cd, cp, mv, rm, e depois evolua para find, grep, vim e less.
📂 Comandos Básicos Essencial ▶
ls Lista arquivos e diretórios do diretório atual
ls -l Lista com detalhes (permissões, dono, tamanho, data)
ls -a Lista TODOS os arquivos, incluindo ocultos (que começam com .)
ls -la Lista TODOS os arquivos com detalhes (mais usado do dia a dia)
ls -lh Lista com tamanhos legíveis (KB, MB, GB)
ls -lt Lista ordenado por data de modificação (mais recentes primeiro)
ls -ltr Lista ordenado por data (mais antigos primeiro)
cd Volta para o diretório home do usuário
cd /caminho Vai para um diretório específico (caminho absoluto)
cd .. Sobe um nível (volta para o diretório pai)
cd - Volta para o diretório anterior (último onde estava)
cd ~ Vai para o diretório home do usuário
cd ../.. Sobe dois níveis de uma vez
pwd Mostra o caminho completo do diretório atual
cp origem destino Copia arquivo ou diretório
cp -r origem destino Copia diretório recursivamente (com todo o conteúdo)
cp -i origem destino Copia perguntando antes de sobrescrever (seguro)
cp -v origem destino Copia mostrando o progresso (verbose)
cp -u origem destino Copia apenas se origem for mais novo que destino
mv origem destino Move ou renomeia arquivo/diretório
mv -i origem destino Move perguntando antes de sobrescrever
mv -v origem destino Move mostrando o que está fazendo
mv arquivo.txt pasta/ Move arquivo para uma pasta
mv antigo.txt novo.txt Renomeia arquivo
rm arquivo Remove arquivo (cuidado: não vai para lixeira!)
rm -i arquivo Remove perguntando antes (mais seguro)
rm -r pasta Remove diretório recursivamente (com todo o conteúdo)
rm -rf pasta Remove forçadamente sem perguntar (PERIGOSO!)
mkdir nome_pasta Cria um novo diretório
mkdir -p pasta/subpasta Cria diretórios aninhados (pai e filho) de uma vez
rmdir nome_pasta Remove diretório VAZIO
touch arquivo.txt Cria um arquivo vazio ou atualiza a data de modificação
cat arquivo.txt Exibe o conteúdo do arquivo na tela
cat -n arquivo.txt Exibe com números de linha
🔍 find Buscar arquivos ▶
find . -name "*.txt" Busca arquivos .txt no diretório atual
find /home -type f -name "*.pdf" Busca arquivos PDF em /home
find . -type d -name "backup" Busca diretórios chamados "backup"
find . -size +100M Busca arquivos maiores que 100MB
find . -mtime -7 Arquivos modificados nos últimos 7 dias
find . -name "*.log" -exec rm {} \; Remove todos os arquivos .log encontrados
find . -empty Busca arquivos e diretórios vazios
🔎 grep Buscar texto ▶
grep "erro" log.txt Busca "erro" no arquivo log.txt
grep -i "erro" log.txt Busca ignorando maiúsculas/minúsculas
grep -r "erro" /var/log/ Busca recursivamente em todos os arquivos da pasta
grep -n "erro" log.txt Mostra o número da linha onde encontrou
grep -l "erro" *.log Lista apenas os nomes dos arquivos que contém "erro"
grep -v "erro" log.txt Mostra linhas que NÃO contém "erro" (inverte)
grep -c "erro" log.txt Conta quantas vezes "erro" aparece
ps aux | grep nginx Busca processos do nginx (pipe com ps)
✏️ vim Editor de texto ▶
vim arquivo.txt Abrir arquivo no VIM
i Entrar no modo INSERT (editar texto)
Esc Voltar para o modo NORMAL
:w Salvar o arquivo
:wq Salvar e sair
:q! Sair sem salvar (forçado)
dd Apagar a linha atual
yy Copiar (yank) a linha atual
p Colar (paste) depois do cursor
u Desfazer (undo) última ação
Ctrl + r Refazer (redo) ação desfeita
/palavra Buscar "palavra" para frente
?palavra Buscar "palavra" para trás
n Próxima ocorrência da busca
gg Ir para o início do arquivo
G Ir para o final do arquivo
:set number Mostrar números de linha
:set nonumber Ocultar números de linha
:set relativenumber Mostrar números relativos (útil para navegação)
:%s/antigo/novo/g Substituir "antigo" por "novo" em todo o arquivo
:w !sudo tee % Salvar arquivo com permissão sudo (sem abrir como root)
📄 less Visualizador ▶
less arquivo.txt Abrir arquivo no less
less -N arquivo.txt Mostrar números de linha
less -S arquivo.txt Cortar linhas longas (útil para logs)
Espaço / Page Down Avançar uma página
b / Page Up Voltar uma página
g Ir para o início do arquivo
G Ir para o final do arquivo
j / ↓ Avançar uma linha
k / ↑ Voltar uma linha
/palavra Buscar "palavra" para frente
?palavra Buscar "palavra" para trás
n Próxima ocorrência da busca
= Mostrar informações do arquivo (linha, %, tamanho)
R Recarregar o arquivo (útil para logs em tempo real)
q Sair do less
tail -f log.txt | less Pipelina logs em tempo real para o less
