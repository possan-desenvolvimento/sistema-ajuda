💡 O que é o N8N?
N8N é uma ferramenta de automação de fluxos de trabalho (workflow automation). Cada nó (node) representa uma ação: HTTP Request, IF, Merge, Webhook, etc. Você conecta os nós para criar automações completas.
🔧 Core - Nós Básicos Essencial ▶
Manual Trigger Inicia o workflow manualmente (botão "Execute Workflow")
Schedule Trigger Executa o workflow em intervalos (CRON - ex: todos os dias às 8h)
Webhook Recebe requisições HTTP e inicia o workflow (URL pública)
Set Define ou modifica valores no fluxo de dados
IF Condicional - bifurca o fluxo baseado em uma condição (true/false)
Switch Multi-condicional - bifurca o fluxo para diferentes caminhos
Merge Combina dados de duas ou mais branches
Code (JavaScript) Executa código JavaScript customizado
NoOp Nó vazio - útil para testes e debugging
🌐 HTTP / API Integrações ▶
HTTP Request Faz requisições HTTP (GET, POST, PUT, DELETE, PATCH)
HTTP Request - GET Busca dados de uma API (ex: https://api.exemplo.com/usuarios)
HTTP Request - POST Envia dados para uma API (ex: criar novo usuário)
HTTP Request - Com Headers Adiciona headers (Authorization, Content-Type, etc)
Webhook (Response) Retorna uma resposta para quem chamou o webhook
📊 Dados - Processamento Transformação ▶
Filter Filtra itens do array baseado em uma condição
Sort Ordena dados por campo (ASC/DESC)
Limit Limita a quantidade de itens processados
Aggregate Agrupa dados (COUNT, SUM, AVG, MIN, MAX)
Split In Batches Divide dados em lotes (ex: 100 itens por lote)
Remove Duplicates Remove itens duplicados baseado em um campo
🔄 Dados - Transformação Mapeamento ▶
Item Lists Converte array em objetos ou vice-versa
Spreadsheet (CSV) Lê/Escreve arquivos CSV
XML Converte dados entre JSON e XML
HTML Extract Extrai dados de páginas HTML (Web Scraping)
JSON Converte strings JSON para objetos e vice-versa
