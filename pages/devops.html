💡 O que é Docker?
Docker é uma plataforma que permite criar, executar e gerenciar containers. Containers são ambientes isolados que rodam aplicações com todas as suas dependências. Hoje, o Compose integrado é chamado com docker compose; o comando separado docker-compose aparece em instalações antigas.
⚠️ Antes de apagar qualquer coisa

Confira o alvo com docker ps -a, a imagem com docker images e os volumes antes de usar docker system prune -a ou docker compose down -v.

MAPA MENTAL

Entenda as peças antes dos comandos

Docker fica muito mais simples quando cada recurso tem uma responsabilidade clara.

📦Imagem

Modelo imutável criado por um Dockerfile ou baixado de um registry.

docker pull nginx:1.25
🚀Container

Processo criado a partir de uma imagem, com estado e configuração próprios.

docker run --name web nginx
💾Volume

Dados persistentes que continuam existindo mesmo após recriar o container.

docker volume ls
🔗Rede

Canal privado para containers conversarem usando nomes de serviço.

curl http://api:8080
📋 docker ps Listar containers ▶
docker ps Lista containers em execução
docker ps -a Lista TODOS os containers (incluindo parados)
docker ps -q Lista apenas os IDs dos containers
docker ps -a -q Lista IDs de TODOS os containers
docker ps --filter "status=exited" Lista apenas containers parados
docker ps --filter "name=nginx" Filtra containers pelo nome
docker ps -a --format "table {{.Names}}\t{{.Status}}" Lista com formato personalizado (nome + status)
🚀 docker run Criar container ▶
docker run nginx Cria e executa um container com a imagem nginx
docker run -d nginx Roda o container em background (detached mode)
docker run -p 8080:80 nginx Mapeia a porta 8080 do host para a porta 80 do container
docker run --name meu-nginx nginx Dá um nome ao container
docker run -v /host:/container nginx Monta um volume (pasta do host dentro do container)
docker run -e VARIAVEL=valor nginx Define variável de ambiente
docker run --rm nginx Remove o container automaticamente quando parar
docker run -it ubuntu bash Roda container interativo com bash (modo interativo)
docker run -d --restart always nginx Reinicia automaticamente se o container cair
⏹️ docker stop / start / restart Controlar containers ▶
docker stop container_id Para um container em execução (graceful shutdown)
docker stop -t 10 container_id Para com timeout de 10 segundos
docker kill container_id Força a parada do container (SIGKILL)
docker start container_id Inicia um container que está parado
docker start -a container_id Inicia e anexa ao terminal (modo interativo)
docker restart container_id Reinicia um container (stop + start)
docker stop $(docker ps -q) Para TODOS os containers em execução
docker stop $(docker ps -aq) Para TODOS os containers (incluindo parados)
📜 docker logs / exec Logs e execução ▶
docker logs container_id Exibe os logs do container
docker logs -f container_id Logs em tempo real (follow)
docker logs --tail 100 container_id Mostra as últimas 100 linhas
docker logs --since 1h container_id Logs da última hora
docker exec -it container_id bash Entra no container com bash (modo interativo)
docker exec container_id ls -la Executa comando no container sem entrar
docker exec -d container_id touch /tmp/arquivo Executa comando em background
docker exec -e VAR=valor container_id env Executa com variável de ambiente
🖼️ docker images / rmi / build Gerenciar imagens ▶
docker images Lista todas as imagens baixadas
docker images -a Lista TODAS as imagens (incluindo intermediárias)
docker images -q Lista apenas os IDs das imagens
docker pull nginx:latest Baixa uma imagem do Docker Hub
docker pull nginx:1.21 Baixa uma versão específica da imagem
docker rmi imagem_id Remove uma imagem
docker rmi -f imagem_id Remove imagem forçadamente
docker rmi $(docker images -q) Remove TODAS as imagens
docker build -t minha-imagem . Constrói uma imagem a partir do Dockerfile
docker build -t minha-imagem:1.0 . Constrói com tag específica
docker build --no-cache -t minha-imagem . Constrói sem usar cache (força rebuild)
docker tag imagem_id usuario/repo:tag Cria uma tag para a imagem
docker push usuario/repo:tag Envia a imagem para o Docker Hub
🧹 docker rm / prune Limpar containers ▶
docker rm container_id Remove um container (deve estar parado)
docker rm -f container_id ⚠️ Remove um container forçadamente, mesmo rodando.
docker rm -v container_id ⚠️ Remove o container e os volumes associados.
docker rm $(docker ps -aq) ⚠️ Remove TODOS os containers parados.
docker container prune ⚠️ Remove todos os containers parados.
docker image prune Remove imagens não utilizadas
docker system prune -a ⚠️ Limpa containers, imagens, redes e cache não utilizados.
🔍 docker inspect / network / volume Inspeção e redes ▶
docker inspect container_id Mostra detalhes do container (JSON)
docker inspect --format '{{.NetworkSettings.IPAddress}}' container_id Mostra apenas o IP do container
docker network ls Lista redes disponíveis
docker network create minha-rede Cria uma rede personalizada
docker network connect rede container Conecta um container a uma rede
docker volume ls Lista volumes
docker volume create meu-volume Cria um volume personalizado
📦 docker-compose Orquestração ▶
docker compose up Sobe os serviços (logs no terminal)
docker compose up -d Sobe os serviços em background
docker compose down Para e remove serviços, redes e volumes
docker compose down -v Remove também os volumes
docker compose logs -f Logs de todos os serviços em tempo real
docker compose logs -f serviço Logs de um serviço específico
docker compose ps Status dos serviços
docker compose restart Reinicia todos os serviços
docker compose restart serviço Reinicia um serviço específico
docker compose exec serviço bash Entra no container do serviço
docker compose exec serviço comando Executa comando no serviço
docker compose up -d --build Sobe com rebuild das imagens
docker compose config Valida e mostra o docker-compose.yml
docker compose -f docker-compose.prod.yml up Usa um arquivo específico
🧱 Dockerfile Criar imagens ▶
FROM node:22-alpineEscolhe a imagem base da aplicação.
WORKDIR /appDefine o diretório de trabalho dentro da imagem.
COPY package*.json ./Copia arquivos de dependência antes do código para aproveitar o cache.
RUN npm ci --omit=devInstala dependências de forma reprodutível durante o build.
COPY . .Copia o código da aplicação para a imagem.
EXPOSE 3000Documenta a porta usada pela aplicação (não publica a porta sozinho).
CMD ["node", "server.js"]Define o processo padrão que inicia o container.
🩺 Troubleshooting Investigar falhas ▶
docker inspect container_idConsulta configuração, rede, mounts e estado detalhado.
docker statsAcompanha CPU, memória, rede e I/O dos containers.
docker compose psMostra o estado dos serviços do projeto Compose.
docker compose logs --tail=100 servicoLê os logs recentes de um serviço específico.
docker compose configRenderiza o Compose final e ajuda a encontrar erros de YAML e variáveis.
docker compose exec servico shEntra no serviço usando sh quando bash não está instalado.
